# Task 18：素材列表按课程筛选

## 目标

在素材列表增加课程筛选，使用户可以查看与指定课程关联的素材，并与现有关键词、类型、状态筛选共同使用。

## 产品依据

`docs/product-v1.md` 已明确素材列表支持课程筛选；Task 16 已建立素材与课程多对多关系。

## 范围与边界

1. 素材列表增加单选课程筛选。
2. 默认“全部课程”时行为与当前一致。
3. 选择某门课程后，只返回与该课程已建立关联的素材。
4. 课程筛选与现有关键词、类型、状态条件可任意组合，并共同作用于：
   - total
   - 当前分页结果
5. 任一筛选条件变化后回到第一页。
6. 翻页时保留关键词、课程、类型、状态全部条件。
7. 课程候选集沿用当前逐页读取完整候选集的策略，不提高后端 page_size 上限。
8. 停用课程仍可作为筛选条件，用于查看既有关联素材。
9. 不存在或非法课程 ID 按现有 API 风格明确拒绝，不静默忽略。
10. 不修改素材与课程关联关系本身。
11. 不新增 schema / migration。

## 明确不做

- 多课程同时筛选
- 按课程优先排序（Task 17 负责备课页优先展示）
- 人群 / 行业 / 标签筛选
- AI 推荐
- 相关度打分
- 素材家族
- 新搜索基础设施
- 新缓存层

## 验收

至少验证：

1. 默认全部课程时与当前行为一致。
2. 选择一门课程只返回与该课程关联的素材。
3. 同一素材关联多门课程时，在对应每门课程筛选下均可返回。
4. 未关联指定课程的素材不返回。
5. 停用课程可正常筛选既有关联素材。
6. 课程 + 关键词组合正确。
7. 课程 + 类型组合正确。
8. 课程 + 状态组合正确。
9. 课程 + 关键词 + 类型 + 状态四项组合正确。
10. total 与分页结果遵守全部筛选条件。
11. 条件变化回到第一页。
12. 翻页时保留全部筛选条件。
13. 不存在或非法课程 ID 被明确拒绝。
14. 1280px / 375px 下筛选控件和分页正常，无明显横向溢出。
15. 无 schema / migration 变更。
16. `make check` 通过。
17. `make smoke` 通过。
18. `make e2e` 通过。
