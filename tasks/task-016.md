# Task 16：素材与课程多对多关系

## 目标

建立素材与课程的多对多关系，使一条素材可以关联多门课程，并可在素材编辑与详情中维护、查看这些关联。

## 产品依据

`docs/product-v1.md` 已明确：

- 素材与课程为多对多关系；
- 该关系用于表示某素材通常适合哪些课程；
- 它只影响推荐顺序和筛选，不限制素材实际使用范围。

## 范围与边界

1. 新增素材与课程多对多关系表，并使用 Alembic migration。
2. 一条素材可关联 0 到多门课程。
3. 一门课程可关联 0 到多条素材。
4. 素材编辑页支持选择多门课程。
5. 素材详情页展示已关联课程。
6. 素材读取 / 更新 API 支持课程关联。
7. 编辑时未选择课程表示该素材当前无课程关联。
8. 课程被停用后，既有素材关联关系保留，不自动删除。
9. 课程关联不影响素材是否可以在其他课程场次中实际使用。
10. 不改变当前快速录入流程；快速录入仍只要求标题、类型、正文。
11. 课程候选集沿用当前大候选集逐页读取策略，不提高后端 page_size 上限。

## 明确不做

- 备课页的课程优先排序（由后续 Task 实现）
- 素材列表课程筛选
- 按课程限制素材可见性或可使用性
- 自动推断课程关联
- AI 推荐
- 素材家族
- 标签 / 人群 / 行业关联
- 删除课程时的新增业务语义
- 通用关系管理框架

## 验收

至少验证：

1. migration 单一 head。
2. 旧素材迁移后课程关联为空且可正常读取。
3. 素材可关联一门课程。
4. 素材可关联多门课程。
5. 可以清空全部课程关联。
6. 更新基础字段时未误删既有课程关联。
7. 明确提交课程关联时按提交结果整体替换。
8. 非法 / 不存在课程 ID 被明确拒绝，且素材关联不发生部分更新。
9. 停用课程仍可作为既有关联被正常读取和展示。
10. 快速录入行为不回退。
11. 素材详情显示关联课程。
12. 桌面与 375px 编辑 / 详情正常。
13. migration upgrade 正常。
14. `make check` 通过。
15. `make smoke` 通过。
16. `make e2e` 通过。
