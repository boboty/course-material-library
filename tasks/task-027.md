# Task 27：草稿待补全

## 目标
建立“随手录入 → 以后补全”的明确工作入口，让低成本快速录入真正形成可持续工作流。

## 产品依据
`docs/product-v1.md` 将“草稿待补全”列为 V1 主要页面。

## 范围与边界
1. 增加独立的“草稿待补全”入口。
2. 仅展示状态为“草稿”的素材。
3. 默认按现有稳定时间顺序展示，不引入推荐分数。
4. 可直接进入素材编辑页完成补全。
5. 页面至少展示足以判断是否值得补全的信息：标题、类型、正文摘要及已有关键补充信息。
6. 编辑并离开草稿状态后，该素材应从待补全列表消失。
7. 保持快速录入低门槛；不强迫录入时填写更多字段。
8. 手机端可正常使用。

## 明确不做
- 自动补全文案
- AI 整理
- 批量状态修改
- 完成度评分
- 待办提醒系统

## 验收
至少验证：仅草稿、编辑后移出、分页或完整候选行为与现有列表契约一致、空列表、1280px / 375px、入口可达、make check / smoke / e2e / diff-check。
最终由 Independent Verifier 按 `AGENTS.md` 独立验收。
