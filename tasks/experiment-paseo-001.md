# Paseo Experiment 001：Demo 确认词严格匹配边界测试

## 背景

Task 9 已冻结确认规则：

只有精确输入 `yes` 才允许执行 demo-data / demo-clean。
任何其他输入、直接回车或 EOF 都必须取消，且不得修改数据库。

本实验不改变该业务规则，只补充边界验证。

## 任务

检查当前 Demo 数据确认逻辑和现有测试。

补充自动化测试，至少验证：

- `yes`：允许执行
- ` yes`：取消
- `yes `：取消
- `Yes`：取消
- `YES`：取消
- 空字符串：取消
- EOF：取消

取消时：

- 退出码为 0
- 不进入数据库事务
- 数据零变化

如果当前实现不能满足上述规则，做最小修复。

## 约束

- 不修改冻结业务语义
- 不修改 schema / migration
- 不修改 API 契约
- 不修改前端
- 不增加新的环境判断
- 不增加跳过确认开关
- 不提交、不 push

## 验收

至少执行：

- 相关单元测试
- make check
- git diff --check

Verifier 必须独立检查代码与测试，不接受 Developer 的自评作为验收证据。

最终结论只能是：

- PASS
- RC
- BLOCKED
