# Task 26：复核到期与连续两次差评提示

## 目标
实现 V1 的两类系统提示：复核日期已过期、最近连续两次明确效果为“差”。

## 依赖
Task 25。

## 产品依据
`docs/product-v1.md` 规定：
- 仅设置了复核日期且已经过期时提示；无日期永不过期。
- 最近连续两次明确标记为“差”时提示“建议复核”，并展示两次使用场次的人群、客户和课程。
- 系统提示与人工状态严格分离，不得自动修改素材状态。

## 范围与边界
1. 素材列表支持查看“复核已过期”素材。
2. 复核日期为空时绝不视为过期。
3. “连续两次差”按最近的实际已用记录判断。
4. 中间若出现一次“好”或其他明确非差结果，应中断连续差。
5. 计划、未用不得参与连续差判断；“未评”如何处理需按产品语义明确并测试，不能偷偷等同于“一般”。
6. 连续两次差提示展示对应两次场次的人群、客户、课程。
7. 提示只提供信息，不自动改为待更新 / 退役。
8. 提示可在素材列表预设筛选或等价入口中访问，不单独建设关注面板。

## 明确不做
- 失败原因自动分析
- 高频/低频告警
- 90 天统计告警
- AI 推荐
- 自动状态流转

## 验收
至少验证：过期/未过期/无日期、连续两次差、被好结果打断、未用/计划排除、未评语义符合定义、两次场次信息正确、不改状态、1280px / 375px、make check / smoke / e2e / diff-check。
最终由 Independent Verifier 按 `AGENTS.md` 独立验收。
