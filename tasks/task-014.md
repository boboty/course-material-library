# Task 14：Markdown 批量导入

## 目标

实现稳定、简单的 Markdown 批量导入。

用户粘贴符合约定格式的 Markdown，系统按内容块拆分，每个内容块生成一条草稿素材。

## 产品依据

`docs/product-v1.md` 已明确：

- V1 支持稳定、简单的 Markdown 批量导入格式
- 应用负责按约定格式拆分素材
- 每个内容块生成一条草稿素材
- 素材提取、整理和拆分可在系统外借助 AI 完成
- V1 本身不内置 AI 整理能力

## 格式

采用固定格式：

- 二级标题 `## ` 作为一条素材标题
- 标题之后、下一个二级标题之前的正文作为素材正文
- 导入素材统一为草稿
- 类型不由 Markdown 推断，保持未填写

示例：

```markdown
## 一个故事

正文内容……

## 一个案例

正文内容……
```

## 范围与边界

1. 增加批量导入页面和入口。
2. 用户粘贴 Markdown 后先解析并显示待导入条目数量。
3. 只有同时具备非空标题和非空正文的内容块才可导入。
4. 格式错误应明确提示，不部分导入。
5. 确认导入后，在一个事务中创建全部素材。
6. 任一条创建失败时整体回滚。
7. 导入结果全部为草稿、type=null。
8. 允许与已有素材同标题，不新增去重规则。
9. 成功后明确显示导入数量并提供返回素材列表入口。

## 明确不做

- 文件上传
- AI 自动拆分
- 自动判断素材类型
- YAML / front matter
- 标签、课程、人群等字段导入
- 同标题去重
- 部分成功
- 导入历史
- schema / migration 变更

## 验收

至少验证：

- 单条导入
- 多条导入
- 中文 / 英文正文
- 前后空白处理
- 缺标题
- 缺正文
- 空输入
- 格式错误时零写入
- 中途失败时事务整体回滚
- 同标题允许导入
- 导入后均为草稿且 type=null
- 1280px / 375px 页面可用
- `make check`
- `make smoke`
- `make e2e`

最终由 Independent Verifier 按 AGENTS.md 独立验收。
