# Task 12：素材基础编辑

## 目标

支持从素材详情进入编辑，修改当前已经存在于数据模型中的基础字段：

- 标题
- 类型
- 正文
- 状态

保存后返回素材详情并展示最新内容。

本 Task 只建立素材基础编辑闭环，不扩展尚未建模的素材字段。

## 产品依据

`docs/product-v1.md` 已明确主要页面包含“快速录入 / 编辑”。

当前素材实体已经具备：

- title
- type
- body
- status

当前项目尚未具备素材编辑能力。

## 范围与边界

1. 后端增加素材更新能力。

2. 支持修改：
   - 标题
   - 类型
   - 正文
   - 状态

3. 编辑入口从素材详情页进入。

4. 编辑页加载当前素材已有值。

5. 保存成功后返回素材详情页，并展示最新内容。

6. 更新时继续遵守现有素材规则：
   - 标题不能为空
   - 类型必须为现有素材类型
   - 状态必须为现有五种状态
   - 非草稿素材必须具备类型和正文

7. 标题仍允许重复，不新增唯一约束。

8. 如果把草稿改为非草稿状态，而类型或正文不完整，应明确拒绝保存。

9. 更新不存在的素材返回现有风格的 404。

10. 不新增 schema / migration。

## 明确不做

本 Task 不做：

- 标签
- 适用人群
- 适用行业
- 支撑判断
- 讲法要点
- 来源备注
- 案例类别
- 复核日期
- Demo 最后验证日期
- 退役原因
- 素材家族
- 删除
- 版本历史
- 自动保存
- 并发编辑控制

不要为了以后完整素材编辑提前建立复杂通用表单框架。

## 验收

至少验证：

1. 从素材详情可以进入编辑。

2. 编辑页正确显示当前标题、类型、正文和状态。

3. 修改标题、类型、正文后保存成功，详情页显示新值。

4. 修改状态后保存成功，Badge 与最新状态一致。

5. 标题为空时不能保存。

6. 非法类型不能被接受。

7. 非法状态不能被接受。

8. 草稿可以保存当前允许的内容状态。

9. 非草稿素材缺少类型或正文时保存失败。

10. 同标题素材仍然允许存在。

11. 编辑不存在的素材得到 404。

12. 桌面和 375px 下编辑、保存、返回详情均正常可用。

13. 不修改 schema / migration。

14. `make check` 通过。

涉及页面完整流程，执行：

- `make e2e`

涉及后端更新接口，执行：

- `make smoke`

最终由 Independent Verifier 按 AGENTS.md 执行独立验收。
