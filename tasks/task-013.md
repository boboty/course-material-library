# Task 13：素材类型筛选与正文关键词搜索

## 目标

完善素材列表查找能力：

- 增加素材类型筛选
- 将关键词搜索从仅标题扩展为标题或正文匹配
- 与现有状态筛选、分页共同工作

## 产品依据

`docs/product-v1.md` 已明确素材列表支持关键词搜索、类型筛选和状态筛选。当前尚未建模标签，因此本 Task 只实现标题 + 正文关键词搜索。

## 范围与边界

1. 增加单选类型筛选：全部 / 故事 / 案例 / Demo / 金句 / 段子 / 行业素材。
2. 现有关键词参数继续沿用，匹配标题或正文。
3. 正文为空时查询正常。
4. 关键词、类型、状态可以任意组合，并共同作用于 total 和分页。
5. 任一查询条件变化后回到第一页。
6. 翻页时保留全部查询条件。
7. 非法类型参数按现有 API 校验风格返回明确错误，不静默忽略。
8. 不修改 schema / migration。

## 明确不做

- 标签搜索或筛选
- 课程 / 人群 / 行业筛选
- 多类型选择
- 相关度排序
- 搜索高亮
- 语义搜索、向量搜索
- 新搜索基础设施

## 验收

至少验证：

- 六种类型及“全部类型”
- 标题关键词命中
- 正文关键词命中
- 正文为空
- 关键词 + 类型
- 关键词 + 状态
- 关键词 + 类型 + 状态
- total / 分页正确
- 条件变化回第一页
- 翻页保留全部条件
- 非法类型被拒绝
- 1280px / 375px 正常
- `make check`
- `make smoke`
- `make e2e`

最终由 Independent Verifier 按 AGENTS.md 独立验收。
