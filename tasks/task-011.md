# Task 11：素材快速录入标题重复提示收口

## 目标

在素材快速录入时，对完全相同标题的已有素材给出明确重复提示，但不阻止继续保存。

本 Task 只处理精确标题重复，不做模糊匹配或语义相似度判断。

## 产品依据

`docs/product-v1.md` 已明确：

- 录入素材时可以进行简单的标题重复提示
- V1 不做复杂语义相似度判断

## 范围与边界

1. 用户输入标题后，在合适时机检查是否存在完全相同标题的已有素材。

2. 如果存在：
   - 页面明确提示已有同标题素材
   - 提示不阻止继续保存
   - 用户仍可创建新的素材

3. 如果不存在：
   - 不显示重复提示
   - 正常保存流程不受影响

4. 重复判断必须基于后端真实数据，不仅检查当前页面本地状态。

5. 精确标题匹配沿用项目现有标题查询能力。
   如果现有实现已经具备部分能力，应优先复用并收口，不重复设计。

6. 不改变“允许同标题素材存在”的现有业务规则。

## 明确不做

本 Task 不做：

- 模糊标题匹配
- 大小写智能归一化
- 去空格或复杂标准化规则
- 正文相似度
- 向量检索
- AI 相似素材判断
- 自动阻止重复保存
- 自动合并素材
- 素材家族
- schema / migration 变更

## 验收

至少验证：

1. 输入一个数据库中不存在的标题时，不显示重复提示。

2. 输入一个已有完全相同标题时，显示明确提示。

3. 出现重复提示后，仍可继续保存新素材。

4. 保存后数据库中允许存在两条同标题素材。

5. 修改标题为不同值后，重复提示消失。

6. 重复提示不会误伤正常快速录入流程。

7. 桌面和 375px 宽度下提示与保存操作均正常可用。

8. 不修改 schema / migration。

9. `make check` 通过。

涉及页面流程，执行：

- `make e2e`

如涉及后端查询契约，执行：

- `make smoke`
