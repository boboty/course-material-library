# Task 22：素材列表人群、行业与标签筛选

## 目标
补齐素材列表中人群、行业、标签的搜索与筛选，使 V1 的素材查找能力覆盖产品定义中的主要维度。

## 依赖
Task 20、Task 21。

## 产品依据
`docs/product-v1.md` 规定素材列表支持关键词搜索标题、正文、标签，以及类型、课程、人群、行业、状态、标签筛选。

## 范围与边界
1. 关键词 q 扩展为匹配标题、正文、标签。
2. 增加单选人群筛选。
3. 增加单选行业筛选。
4. 增加单选标签筛选；标签候选从已有素材标签中取得。
5. 与现有 q / type / course_id / status 任意组合，所有条件共同作用于 total 与分页。
6. 任一筛选条件变化回第一页。
7. 翻页保留全部查询条件。
8. 人群、行业候选逐页取全，不提高 page_size。
9. 无匹配时明确显示空结果。
10. 不改变关联关系与素材状态。

## 明确不做
- 多选筛选
- 相关度排序
- AI 推荐
- 向量检索
- 可搜索大候选下拉新组件
- 素材家族逻辑

## 验收
至少验证：每一单项筛选、q 命中标签、全部条件组合、total / 分页一致、条件变化回第一页、翻页保留、非法/不存在 ID 行为明确、1280px / 375px、无 schema 变更（除非实现确有必要且需说明）、make check / smoke / e2e / diff-check。
最终由 Independent Verifier 按 `AGENTS.md` 独立验收。
