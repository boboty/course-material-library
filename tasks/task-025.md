# Task 25：素材复核、Demo 验证、案例类别与退役原因

## 目标
补齐 V1 中剩余的素材业务字段，使素材能够表达需要复核、Demo 可用性、案例性质与退役原因。

## 产品依据
`docs/product-v1.md` 规定素材支持：案例类别、复核日期、Demo 最后验证可用日期、退役原因。

## 范围与边界
1. 增加可选复核日期。
2. 增加可选 Demo 最后验证可用日期。
3. 增加可选案例类别：A 真实案例 / B 情境案例。
4. 增加可选退役原因。
5. 案例类别仅在素材类型为“案例”时允许设置；其他类型明确拒绝或清空，行为需一致且有测试。
6. Demo 最后验证日期仅在类型为“Demo”时允许设置；其他类型行为同上。
7. 退役原因仅在状态为“退役”时允许设置；离开退役状态后的处理规则需明确并保持一致。
8. 编辑与详情页支持维护和展示；无值时不制造提示。
9. 快速录入仍不增加额外必填项。
10. 需要 schema / migration 时保持单一 Alembic head。

## 明确不做
- 自动设置复核日期
- 自动修改状态
- 复核过期提示（后续 Task）
- Demo 自动运行验证
- AI 判断案例真假

## 验收
至少验证：四字段增改清空、类型/状态约束、字段切换后的确定性行为、旧素材迁移兼容、详情仅展示有效值、1280px / 375px、make check / smoke / e2e / diff-check。
最终由 Independent Verifier 按 `AGENTS.md` 独立验收。
