# Task 15：素材核心补充字段

## 目标

补充素材当前缺失但对长期课程资产管理最直接有价值的三个字段：

- 支撑什么判断
- 讲法要点
- 来源备注

并支持在素材编辑和详情中维护、查看。

## 产品依据

`docs/product-v1.md` 已将以下内容定义为素材主要字段：

- 支撑什么判断
- 讲法要点
- 来源备注，仅内部可见

## 范围与边界

1. 为素材增加三个可选文本字段：
   - `supporting_judgment`
   - `speaking_notes`
   - `source_note`
2. 使用 Alembic migration 修改 schema。
3. 三个字段均允许为空。
4. 快速录入流程保持不变，仍只要求标题、类型、正文。
5. 素材编辑页可以修改三个字段。
6. 素材详情页展示有内容的字段；为空时不需要占据大块页面空间。
7. 更新接口支持三个字段并沿用当前基础编辑规则。
8. `source_note` 属内部信息，不得进入 Demo、公开 fixture、日志或其他公开展示。

## 明确不做

- 标签
- 适用人群
- 适用行业
- 案例类别
- 复核日期
- Demo 最后验证日期
- 退役原因
- 素材家族
- 课程关系
- AI 自动生成这些字段
- 搜索这些字段

## 验收

至少验证：

- migration 单一 head
- 旧素材迁移后字段为空且可正常读取
- 三字段可分别保存、修改、清空
- 基础四字段编辑行为不回退
- 快速录入仍无需填写新增字段
- 详情页仅展示实际有值的补充字段
- `source_note` 不进入公开测试数据和日志
- 1280px / 375px 编辑与详情正常
- migration upgrade 正常
- `make check`
- `make smoke`
- `make e2e`

最终由 Independent Verifier 按 AGENTS.md 独立验收。
