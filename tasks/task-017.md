# Task 17：备课素材按当前课程优先展示

## 目标

在场次备课选择素材时，优先展示与当前场次主课程已关联的素材，同时仍允许搜索和选择全库素材。

## 产品依据

`docs/product-v1.md` 已明确：

- 选择素材时可搜索全库；
- 本课程关联素材优先展示；
- 不限制只能选择本课程素材。

## 前置条件

依赖 Task 16 的素材与课程多对多关系。

## 范围与边界

1. 场次计划素材页面读取当前场次主课程。
2. 默认素材候选结果中：
   - 与当前课程关联的素材排在前面；
   - 未关联当前课程的其他素材继续显示在后面。
3. 课程关联只影响排序，不影响候选资格。
4. 搜索时仍查询全库；匹配结果中继续保持“当前课程关联优先”。
5. 已有状态、类型等当前备课页面已支持的查询行为不回退。
6. 同一优先级内保持稳定、可预测的既有排序口径；不要引入推荐分数。
7. 当前课程没有任何关联素材时，页面行为应与现有全库选择基本一致。
8. 停用课程若仍作为历史场次主课程，关联素材优先逻辑仍可正常工作。
9. 不修改素材人工状态，不自动新增课程关联。
10. 不增加新的 schema / migration。

## 明确不做

- 只显示当前课程素材
- 自动推荐
- AI 排序
- 相关度打分
- 人群 / 行业 / 标签排序
- 同客户 / 同集团重复提醒
- 连续差评提醒
- 素材家族
- 新缓存或搜索基础设施

## 验收

至少验证：

1. 当前课程有关联素材时，关联素材排在未关联素材之前。
2. 当前课程有多条关联素材时均处于优先区域。
3. 未关联素材仍可看到并加入计划。
4. 关键词搜索仍覆盖全库。
5. 搜索结果中当前课程关联素材仍优先。
6. 没有关联素材时页面仍正常工作。
7. 已计划素材、加入、撤销等现有流程不回退。
8. 不改变 usage 的既有计划语义。
9. 桌面与 375px 下优先展示和选择流程正常。
10. 无 schema / migration 变更。
11. `make check` 通过。
12. `make smoke` 通过。
13. `make e2e` 通过。
