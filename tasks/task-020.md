# Task 20：素材适用人群与行业

## 目标
为素材增加“适用人群”和“适用行业”多选关系，并在素材编辑与详情中维护和展示，为后续筛选与备课判断提供结构化数据。

## 产品依据
`docs/product-v1.md` 规定素材支持适用人群、适用行业，均为可选多选。

## 范围与边界
1. 素材与人群类型为多对多关系。
2. 素材与行业为多对多关系。
3. 编辑页可从现有基础词表完整选择，候选需逐页取全，不提高现有 page_size。
4. 详情页仅展示已关联的人群与行业。
5. PUT 语义沿用 Task 16：字段省略时保留原关联；显式数组整体替换；空数组清空。
6. 重复 ID、非法 ID、不存在 ID 明确拒绝，且不得部分更新。
7. 现有快速录入流程不增加必填项。
8. 现有素材课程关系、状态、类型、正文等行为不变。
9. 需要 schema / migration 时保持单一 Alembic head。

## 明确不做
- 人群 / 行业筛选
- 标签
- 素材家族
- 重复使用提醒
- AI 推荐
- 新增基础词表语义

## 验收
至少验证：多选、清空、省略保留、非法/不存在/重复 ID、停用或现有词表项展示、超过 100 条候选逐页取全、旧素材迁移兼容、1280px / 375px、make check / smoke / e2e / diff-check。
最终由 Independent Verifier 按 `AGENTS.md` 独立验收。
