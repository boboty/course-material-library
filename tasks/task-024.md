# Task 24：备课同客户与同集团重复使用提醒

## 目标
在备课选择素材时，基于真实 usage 历史提示素材是否已在当前客户或同集团其他客户使用过，帮助避免无意识重复。

## 依赖
Task 23。

## 产品依据
`docs/product-v1.md` 规定：
- 同客户使用过：强提醒；
- 同集团其他客户使用过：弱提醒；
- 展示上次使用日期、课程、人群类型、客户；
- 只在备课选择素材时提示；
- 按素材家族判断；
- 仅提供信息，不阻止继续使用。

## 范围与边界
1. 备课素材候选对每个素材计算其家族历史使用。
2. 当前客户历史使用过同家族任一素材：显示强提醒。
3. 当前客户未用过，但同集团其他客户使用过：显示弱提醒。
4. 同客户优先级高于同集团提醒，不重复叠加两种提醒。
5. 展示最近一次匹配历史的日期、课程、人群类型、客户。
6. 仅统计真实已发生使用事实；计划 / 未用记录不得视为“使用过”。
7. 提醒不限制加入计划。
8. 全库搜索、课程优先排序、加入 / 撤销计划行为不变。
9. 无集团客户只做同客户检查。

## 明确不做
- 高频警告
- 长期未使用警告
- AI 推荐
- 自动禁用素材
- 自动修改素材状态
- 跨集团推断

## 验收
至少验证：同客户强提醒、同集团弱提醒、同客户覆盖同集团、无历史不提醒、计划/未用不算使用、按家族而非单素材 ID、最近一次信息正确、无集团客户、提醒不阻止选择、1280px / 375px、make check / smoke / e2e / diff-check。
最终由 Independent Verifier 按 `AGENTS.md` 独立验收。
