# Task 21：素材标签

## 目标
为素材增加可维护的自由标签，用于描述素材主题与使用线索，并为后续关键词搜索和标签筛选提供基础。

## 产品依据
`docs/product-v1.md` 规定素材支持自由词标签，素材列表搜索范围包含标签，并支持标签筛选。

## 范围与边界
1. 一个素材可有多个标签。
2. 标签为自由词，不建立独立后台词表维护页。
3. 编辑页支持增加、删除标签；详情页展示标签。
4. 标签需做明确且最小的规范化：去除首尾空白；空标签不保存；同一素材内重复标签去重。
5. 不对大小写、同义词、近义词做智能归一化。
6. 快速录入仍只要求标题、类型、正文，不新增标签必填。
7. 不改变现有素材课程、人群、行业关系。
8. 需要 schema / migration 时保持单一 Alembic head。

## 明确不做
- 标签推荐
- 自动打标签
- 标签词典管理
- 语义相似标签合并
- 标签搜索 / 筛选（后续 Task）
- AI 能力

## 验收
至少验证：增删、多标签、去空白、空值忽略、重复去重、编辑读回、详情展示、旧素材迁移兼容、1280px / 375px、make check / smoke / e2e / diff-check。
最终由 Independent Verifier 按 `AGENTS.md` 独立验收。
