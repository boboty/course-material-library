# Task 8：v0.1 展示完成度收口

## 目标

把当前已经可用的产品从“工程 Demo”提升到可以正常展示的 v0.1。不增加业务能力，不重新设计产品。

## 范围与边界

1. 去除 Starter 痕迹：页面 title 为“课程素材库”、`html lang` 为 `zh-CN`、增加符合 BenYan 视觉体系的 favicon；不做动态路由标题。
2. 素材状态（草稿 / 可用 / 主力 / 待更新 / 退役）、使用效果（未评 / 好 / 差）、使用状态（计划 / 已用 / 未用）使用明确的 Badge tone；只复用 Design System 现有 Badge/tone，不新增颜色体系；同一语义全站同一映射。
3. 场次详情页把“课后登记”提升到标题 / 摘要区域作为主要操作，“选择计划素材”保持次级操作；不修改场次业务逻辑，不新增“待登记 / 已登记”状态。
4. 课后登记页增加 sticky 保存区域，桌面与 375px 手机下滚动中保持可触达；可显示当前已用 / 未用等现有页面状态摘要；不做离开拦截，不重构控件形态。
5. 修复卡片标题与 Badge 挤压：Badge 不压缩、不换行，标题可收缩换行，同一列表卡片不因 Badge 产生异常高度；不重新设计卡片组件。
6. 页面收尾：未知前端路由提供 404 页面；列表 / 详情加载期间显示最小 loading 状态；修正词表页“返回客户列表”错误入口；不新建首页 / 仪表盘 / 关注面板。
7. 素材列表使用现有 `material.body` 显示短摘要，控制行数与溢出；无正文时保持合理空状态；不新增后端字段或统计接口。

## 明确不做

素材编辑、素材家族、标签 / 行业 / 人群筛选、使用历史统计、最近使用日期 / 次数、同客户 / 同集团重复提醒、连续差评提示、场次“待登记 / 已登记”状态、课后登记交互重构、全局视觉重设计、新组件库、首页 / 仪表盘、任何 schema / migration / API 契约修改。

## 验收

800px 桌面与 375×812 无明显布局问题；Starter 痕迹消失；状态 / 效果可快速扫读；场次详情主操作层级清楚；课后登记保存动作在手机长页面中始终可触达；卡片标题与 Badge 不互相挤压；404 / loading / 导航文案完整；Task 1–7 业务行为不变；`make check`、`make smoke`、`make e2e` 通过。
