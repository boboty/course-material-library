# Task 23：素材家族与源素材关系

## 目标
支持“同一源素材的不同包装属于一个素材家族”，为重复使用检查提供稳定的归并依据。

## 产品依据
`docs/product-v1.md` 规定素材支持“源素材”，同一源素材的不同包装视为一个素材家族，重复使用检查按素材家族判断。

## 范围与边界
1. 素材可选指定一个“源素材”。
2. 未指定源素材时，该素材自身作为独立家族。
3. 指定源素材后，当前素材与源素材归入同一家族。
4. 源素材选择必须避免自引用。
5. V1 只支持一层源素材关系；若选择的目标自身已有源素材，应归一到其家族根，避免链式嵌套。
6. 编辑页支持选择 / 清除源素材；详情页展示源素材及同家族成员。
7. 删除语义仍不引入；不存在的源素材明确拒绝。
8. 不自动复制正文、标签、课程、人群、行业等字段。
9. 不自动合并历史 usage；重复检查时动态按家族归并。
10. 需要 schema / migration 时保持单一 Alembic head。

## 明确不做
- 多层树结构
- 家族版本管理
- 自动识别相似素材
- AI 合并建议
- 素材内容同步
- 删除 / 拆分家族流程

## 验收
至少验证：独立素材、自引用拒绝、设置/清除源素材、已有子素材再作为目标时归一到根、同家族成员展示、旧素材兼容、无循环链、1280px / 375px、make check / smoke / e2e / diff-check。
最终由 Independent Verifier 按 `AGENTS.md` 独立验收。
